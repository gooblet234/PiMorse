# PiMorse
A drop dead simple morse transmitter with a pi pico 2w as the core.
## Features
- So far, a morse map, so you can read what each letter is in morse code, and navigate through individual letters.
- A beep library I am starting to work on.
- More to come.
## Hardware
- Raspberry Pi Pico 2W with MicroPython firmware
- Probably some buzzer
- Breadboard Jumper wires ([https://www.amazon.com/gp/product/B0BTT31CBC/](url) any works but I used this exact one, even though it is short, it is a really good deal)
- Leds/Resistors 
- SH1106 Screen Module 128x64 1.3' ([https://www.amazon.com/gp/product/B0C3L54TL6/](url) this is the one I used, again, any works, but I chose this as it came in a 5 pack so it was useful in ths case)
- 3d Printed Case (use mine as its super cool yes yes)
